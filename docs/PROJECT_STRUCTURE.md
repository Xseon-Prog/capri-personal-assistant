# Структура проекта Capri

```text
capri-personal-assistant/
├── capri_app/              # Рабочие Python-модули приложения
├── assets/
│   ├── anim/               # Покадровые анимации аватара и режима ожидания
│   └── poses/              # Отдельные изображения-позы
├── bundled/                # Офлайн-архив модели Vosk для установки
├── docs/                   # Команды и документация проекта
├── media/
│   ├── radio/              # Видео радио и кнопки плеера
│   ├── previews/           # GIF/скриншоты для демонстрации, не нужны для запуска
│   ├── banner.png          # Баннер README
│   └── social_preview.png  # Превью репозитория
├── tests/                  # Локальные проверки без запуска GUI
├── tools/                  # Установка, конвертация ресурсов и сборка релиза
├── main.py                 # Совместимая точка входа для run.bat
├── run.bat                 # Запуск приложения
├── setup.bat               # Установка зависимостей и модели речи
└── setup_ai.bat            # Настройка Ollama и локальной модели
```

`config.json`, память SQLite, логи, отчёты, модели и резервные копии хранятся локально и не должны попадать в Git.

Старые `apply_*.py` были одноразовыми миграторами исходников. Их изменения уже объединены в рабочий код; история Git сохраняет возможность восстановить старые версии при необходимости.
