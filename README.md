<p align="center">
  <b>Капри</b> — персональный голосовой ассистент для Windows в киберпанк-стиле. Она работает поверх окон, использует анимированный аватар, распознаёт русскую речь, выполняет команды компьютера, управляет локальным радио и общается с помощью локальной языковой модели.
</p>

> Это независимая пользовательская модификация оригинального проекта. Проект находится в активной разработке; функции и совместимость зависят от версии Windows, установленных компонентов и конфигурации компьютера.

## Возможности

| Область | Возможности |
|---|---|
| Голос | Распознавание русской речи через Vosk; выбор микрофона; настройка усиления и чувствительности; управление громкостью и эффектами голоса |
| Локальный ИИ | Диалог через Ollama и установленную локальную модель, например `qwen3:8b` |
| Голосовые команды настроек | Локальное распознавание поддерживаемых команд для режима ожидания, Радио Найт-Сити, громкости радио и других настроек приложения — без отправки этих команд в Ollama |
| Долговременная память | Сохранение фактов по явной просьбе пользователя, использование сохранённых сведений и удаление фактов по команде |
| Маршрутизация запросов | Разделение команд Windows, коротких разговоров, сложных локальных вопросов и запросов, которым нужны актуальные сведения |
| Поиск | Поддерживаемые запросы о свежих сведениях направляются в существующий сценарий поиска в браузере |
| Управление Windows | Открытие приложений и сайтов, управление окнами и вкладками, клавиатурные действия, системная громкость и яркость на поддерживаемых устройствах |
| Telegram Desktop | Поиск и открытие чатов по имени; распознавание вариантов вроде «найди мне чат мама в Telegram» |
| Радио Найт-Сити | Локальный музыкальный плеер со случайной очередью, предыдущим и следующим треком, Play/Pause, перемоткой, регулировкой громкости и автоматическим переходом к следующей композиции |
| Визуальное оформление радио | Отдельное окно в палитре Капри с зацикленным видео, названием трека и исполнителем; закрытие окна останавливает музыку |
| Режим ожидания | Автоматический переход после бездействия через 20, 40 или 60 секунд либо отключение таймера; отдельный постоянный режим, включаемый вручную |
| Аватар | Прозрачное окно поверх приложений, анимации и позы, CRT/glitch-эффекты, изменение размера, перемещение и закрепление на рабочем столе |
| Панель сообщений | Короткие статусы отображаются ограниченное время; ответы на вопросы могут оставаться дольше. Отображение панели можно отключить |
| Интерфейс Windows | Контекстное меню, отдельные окна ввода и полных ответов, стилизованное окно радио, иконка Капри в заголовках и на панели задач Windows |
| Диагностика ПК | Сбор системной информации и отображение отчёта в интерфейсе Капри |

Полный перечень поддерживаемых команд см. в [КОМАНДЫ.md](КОМАНДЫ.md). Набор голосовых команд зависит от установленной версии обработчиков.

## Радио Найт-Сити

Радио — отдельный локальный плеер. Оно не использует Ollama, облачные ИИ-сервисы или API-токены для воспроизведения музыки.

### Управление

- **Play/Pause** — начать воспроизведение или поставить текущую композицию на паузу.
- **Предыдущий / Следующий** — перемещаться по перемешанной очереди; предыдущий трек доступен из истории прослушивания.
- **Полоса прогресса** — показывать позицию и перематывать композицию.
- **Громкость** — независимо регулировать уровень радио.
- **Обновить библиотеку** — повторно просканировать папку с музыкой.
- **Закрыть** — остановить воспроизведение и закрыть окно радио.

По окончании очереди список перемешивается заново. Форматы аудио зависят от мультимедийного backend Windows/Qt и установленных системных кодеков; используйте распространённые форматы, например MP3, WAV, FLAC, OGG или M4A.

### Папка с музыкой

Музыкальная библиотека хранится отдельно от репозитория:

```text
%USERPROFILE%\Music\Capri\Night City Radio\
```

Поместите собственные аудиофайлы в эту папку, откройте радио и нажмите «Обновить библиотеку». Музыкальные файлы, на которые у пользователя нет прав распространения, не следует публиковать в GitHub. В репозиторий не нужно добавлять личную музыкальную библиотеку.

## Режим ожидания

Капри поддерживает два независимых варианта режима ожидания:

1. **Автоматический режим.** При отсутствии активности запускается циклическая анимация ожидания. Время можно выбрать в меню настроек: 20 секунд, 40 секунд, 1 минута или «Никогда».
2. **Постоянный режим.** Переключатель «Включить режим ожидания» принудительно удерживает аватар в режиме ожидания до отключения этого переключателя. Он сохраняется в локальной конфигурации и имеет приоритет над временными состояниями аватара во время обработки запросов.

В автоматическом режиме прямое взаимодействие с Капри выводит её из ожидания. В постоянном режиме выход выполняется отключением переключателя в настройках.

## Голосовое управление настройками

Поддерживаемые настройки обрабатываются локальным набором правил до обращения к языковой модели. Это позволяет выполнять известные действия без ожидания ответа Ollama.

Примеры формулировок:

| Команда | Действие |
|---|---|
| «Капри, включи Радио Найт-Сити» | Открыть радио и начать воспроизведение |
| «Поставь радио на паузу» / «Продолжи радио» | Пауза или продолжение текущего трека |
| «Следующий трек радио» / «Предыдущий трек радио» | Переключить композицию |
| «Останови радио» | Остановить музыку, не закрывая окно |
| «Закрой радио» | Остановить музыку и закрыть окно |
| «Установи громкость радио на 30» | Установить громкость радио на 30% |
| «Уменьши громкость радио на 30» | Уменьшить текущую громкость на 30 процентных пунктов |
| «Включи режим ожидания» | Включить постоянный режим ожидания |
| «Выключи режим ожидания» | Отключить постоянный режим ожидания |
| «Автоматическое ожидание через 40 секунд» | Изменить таймер автоматического ожидания |

Формулировки должны соответствовать поддерживаемым правилам. Если команда не распознана, проверьте `capri.log` и перечень команд в `КОМАНДЫ.md`.

## Telegram Desktop

Капри умеет искать чаты по имени и открывать найденную переписку. Например:

- «Найди мне чат мама в Telegram».
- «Открой чат с мамой».
- «Перейди в чат мама».

При поиске используется поле поиска списка чатов Telegram Desktop, а не поле поиска стикеров или эмодзи. Капри проверяет заголовок окна после выбора результата. Если совпадение не удалось подтвердить, она должна сообщить об ошибке, а не продолжать ввод текста в неподходящий чат.

Поведение зависит от версии Telegram Desktop и расположения элементов его интерфейса. После обновления Telegram автоматизацию следует проверить вручную.

## Как устроена обработка запросов

```text
Микрофон
   ↓
Распознавание речи (Vosk)
   ↓
Локальный обработчик известных команд и настроек
   ├── Радио / режим ожидания / настройки → прямое действие
   ├── Telegram и Windows → поддерживаемая автоматизация
   └── неизвестный вопрос или разговор
           ↓
       Router (router.py)
         ├── обычный диалог → локальная модель
         ├── сложный вопрос → локальная модель с расширенным контекстом
         └── свежая информация → существующий поиск в браузере
           ↓
       Локальная память SQLite и контекст текущего диалога
           ↓
       Текстовый ответ → синтез речи → аватар Капри
```

Маршрутизатор — локальный механизм выбора сценария. Он не подключает облачные ИИ-провайдеры и не предоставляет модели неограниченный доступ к системе. Облачные интеграции остаются отдельным будущим этапом.

## Установка на Windows

**Нужно:** Windows 10 или 11, микрофон, Python (рекомендуется 3.13 для текущей конфигурации), интернет для установки зависимостей и загрузки модели.

### 1. Получить проект

```powershell
git clone https://github.com/Xseon-Prog/capri-personal-assistant.git
cd capri-personal-assistant
```

Или открой страницу репозитория и выбери **Code → Download ZIP**, затем распакуй архив. Лучше использовать путь без кириллицы, например `C:\capri`.

### 2. Установить Python

Рекомендуется Python 3.13 x64: [загрузки Python для Windows](https://www.python.org/downloads/windows/). При установке включи опцию **Add python.exe to PATH**. Если команда `python` не распознаётся, можно использовать Python Launcher:

```powershell
py -3.13 --version
```

### 3. Установить зависимости и распознавание речи

Запусти **setup.bat** из папки проекта и дождись сообщения об успешном завершении.

### 4. Установить локальную языковую модель

Запусти **setup_ai.bat**. Скрипт проверит доступность Ollama, предложит модель и скачает выбранный вариант.

На одном из компьютеров разработка проверялась с NVIDIA RTX 3060 12 ГБ, 32 ГБ RAM и моделью `qwen3:8b`. Для другого компьютера выбирай размер модели по доступным ресурсам.

Проверить загруженные модели можно командой:

```powershell
ollama list
```

Если команда Ollama не распознаётся в PowerShell, проверь установку Ollama и PATH либо запусти исполняемый файл по полному пути.

### 5. Запустить Капри

Запусти **run.bat**. Аватар и значок появятся на рабочем столе и в системном трее. Щёлкни правой кнопкой по Капри, чтобы открыть контекстное меню.

## Долговременная память

Локальная память реализована на SQLite и хранится вне Git-репозитория, в пользовательской папке приложения. Она рассчитана на факты, которые пользователь попросил сохранить, а не на автоматическую запись всей переписки.

Капри может использовать сохранённые факты в последующих ответах и удалять их по просьбе пользователя. Для переноса кода на другой компьютер используй Git, а личную базу памяти переноси отдельно — только если это действительно нужно.

## Пользовательский интерфейс и аватар

Интерфейс выдержан в стиле Капри:

- почти чёрный фон;
- розовые рамки и основные кнопки;
- бирюзовые и зелёные акценты;
- многострочное окно ввода команды;
- отдельное окно полного ответа с прокруткой и копированием;
- окно системного отчёта;
- контекстное меню и настройки аватара;
- отдельное окно Night City Radio с видео и музыкальным управлением.

Аватар поддерживает прозрачное окно поверх других приложений, анимации и позы, CRT/glitch-эффекты, изменение размера, перемещение, режим ожидания и закрепление на рабочем столе. Для коротких статусов используется сокращённое время отображения; ответы на вопросы могут оставаться на экране дольше.

## Конфигурация

При первом запуске приложение создаёт локальный файл **config.json**. Через меню Капри можно открыть его для настройки.

| Параметр | Назначение |
|---|---|
| `local_ai` | Использовать ли локальную языковую модель |
| `local_model` | Имя модели, установленной в Ollama |
| `use_google_stt` | Дополнительное уточнение распознавания речи через Google |
| `voice` / `tts_engine` | Голос и движок синтеза речи |
| `voice_volume` | Громкость голоса Капри |
| `mic_device` / `mic_gain` / `mic_sensitivity` | Микрофон, усиление и чувствительность |
| `voice_fx` | Сила эффектов голоса |
| `chatter` | Разрешить ли Капри появляться самостоятельно |
| `hide_after_seconds` | Через сколько секунд бездействия скрывать аватар, если это применимо |
| `standby_after_seconds` | Таймер автоматического режима ожидания: 20, 40, 60 секунд или 0 для отключения |
| `manual_standby_enabled` | Постоянный режим ожидания, пока пользователь не отключит его |
| `show_message_hud` | Показывать или скрывать панель сообщений Капри |
| `answer_message_seconds` | Время отображения развёрнутых ответов в панели аватара |
| `avatar_scale` | Масштаб аватара |
| `pin_on_desktop` | Закрепление Капри на рабочем столе |
| `search_when_unsure` | Открывать ли браузерный поиск, когда Капри не знает ответа |
| `sites` / `apps` | Пользовательские сайты и приложения |
| `replies` | Пользовательские ответы на фразы |

Некоторые параметры меняются через контекстное меню и сразу сохраняются. При ручной правке `config.json` может потребоваться перезапуск приложения.

## Приватность и локальные данные

- Vosk распознаёт речь локально.
- Если включён `use_google_stt`, аудио или распознанная фраза могут дополнительно отправляться Google для уточнения — в зависимости от используемого сценария.
- Локальные разговоры через Ollama обрабатываются на компьютере и не тарифицируются как облачные API.
- Голосовой движок Microsoft Edge TTS требует интернета и отправляет текст ответа сервису синтеза речи.
- Команды настроек, режима ожидания и локального радио обрабатываются локально, если они соответствуют известным правилам.
- Радио воспроизводит локальные файлы из пользовательской папки.

Не публикуй личный `config.json`, журналы, базы памяти, секреты API, отчёты диагностики, музыкальные файлы и резервные копии.

## Разработка на нескольких компьютерах

Исходный код хранится в GitHub. На каждом компьютере отдельно установи Python, зависимости, локальную модель и необходимые мультимедийные компоненты.

Перед коммитом проверь список изменений и убедись, что личные файлы игнорируются:

```powershell
git status --short
git check-ignore -v config.json capri.log memory.sqlite3 models reports backups
```

После проверки добавляй только нужные исходники и ресурсы. Не используй `git add .`, если в рабочей папке есть музыка, личные данные или резервные копии.

```powershell
git add main.py actions.py automation.py avatar.py README.md
# Добавь остальные необходимые новые исходники и публичные ресурсы отдельно.
git commit -m "Describe changes"
git push
```

Перед началом работы на другом компьютере получи последние изменения:

```powershell
git pull --ff-only origin main
```

Не добавляй в коммиты личные настройки, логи, базы данных, резервные копии, скачанные модели и личную музыкальную библиотеку.

## Известные ограничения

- Голосовое управление выполняет только формулировки, предусмотренные локальными правилами. Для новых вариантов команд правила нужно расширять и тестировать.
- Автоматизация Telegram Desktop зависит от версии приложения и расположения элементов интерфейса; после обновления Telegram её следует перепроверять.
- Поддержка аудиоформатов радио зависит от Windows, Qt Multimedia и доступных системных кодеков.
- Качество распознавания и синтеза речи зависит от микрофона, настроек Windows, сети и выбранного движка.
- Локальная модель может ошибаться или путать изменяемые сведения. Актуальные данные следует проверять через поиск.
- Проверяй обновления на своём компьютере: окружения Windows и установленное ПО различаются.
