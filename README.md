<p align="center">
  <b>Капри</b> — голосовой ассистент для Windows в киберпанк-стиле. Она живёт поверх окон, использует анимированный аватар и эффекты, распознаёт русскую речь, выполняет команды компьютера и разговаривает с помощью локальной языковой модели.
</p>

> Это независимая пользовательская модификация оригинального проекта. Проект находится в активной разработке; не все функции одинаково проверены на всех конфигурациях Windows.

## Возможности

| Область | Что умеет Капри |
|---|---|
| Голос | Распознаёт команды на русском через Vosk; поддерживает выбор микрофона, настройку чувствительности и громкости голоса |
| Локальный ИИ | Ведёт диалог через Ollama и установленную локальную модель, например `qwen3:8b` |
| Долговременная память | Сохраняет факты по явной просьбе пользователя, использует сохранённые сведения в ответах, умеет забывать факты |
| Маршрутизация запросов | Разделяет известные команды Windows, обычные разговоры, сложные локальные вопросы и запросы, которым могут потребоваться актуальные данные |
| Поиск | Для запросов о текущих событиях использует существующий сценарий открытия поиска в браузере |
| Управление Windows | Открывает приложения и сайты, управляет окнами и вкладками, выполняет поддерживаемые клавиатурные действия |
| Файлы и документы | Открывает папки, создаёт поддерживаемые текстовые файлы и помогает с прикладными действиями |
| Мультимедиа и Telegram | Поддерживает предусмотренные оригинальным проектом команды для мультимедиа и взаимодействия с Telegram Desktop |
| Диагностика ПК | Может собрать системную информацию и показать отчёт в интерфейсе Капри |
| Пользовательский интерфейс | Тёмные окна в розово-бирюзовой палитре: ввод команд, просмотр полных ответов, системных отчётов и меню аватара |
| Аватар | Прозрачное окно поверх приложений, позы и анимации, CRT/glitch-эффекты, перемещение и закрепление на рабочем столе |

Полный список голосовых команд находится в [КОМАНДЫ.md](КОМАНДЫ.md).

## Как устроена обработка запросов

```text
Микрофон
   ↓
Распознавание речи (Vosk)
   ↓
Существующие команды Windows (actions.py)
   ├── известная команда → проверка и выполнение
   └── вопрос или разговор
           ↓
       Router (router.py)
         ├── обычный диалог → локальная модель
         ├── сложный вопрос → локальная модель с расширенным контекстом
         └── свежая информация → существующий поиск в браузере
           ↓
       Локальная память SQLite и история текущего диалога
           ↓
       Текстовый ответ → синтез речи → аватар Капри
```

Маршрутизатор в текущей версии — локальный механизм выбора сценария. Он не подключает облачные ИИ-провайдеры и не предоставляет модели неограниченный доступ к системе. Интеграция OpenAI, Gemini, Groq и других провайдеров остаётся отдельным будущим этапом.

## Установка на Windows

**Нужно:** Windows 10 или 11, микрофон, Python (рекомендуется 3.13 для текущей конфигурации), интернет для установки зависимостей и загрузки модели.

### 1. Получить проект

Клонирование через Git:

```powershell
git clone https://github.com/Xseon-Prog/capri-personal-assistant.git
cd capri-personal-assistant
```

Или открой страницу репозитория и выбери **Code → Download ZIP**, затем распакуй архив. Лучше использовать путь без кириллицы, например `C:\capri`.

### 2. Установить Python

Рекомендуется Python 3.13 x64: [загрузки Python для Windows](https://www.python.org/downloads/windows/). При установке включи опцию **Add python.exe to PATH**.

### 3. Подготовить зависимости и распознавание речи

Запусти файл **setup.bat** из папки проекта и дождись сообщения об успешном завершении.

### 4. Установить локальную языковую модель

Запусти **setup_ai.bat**. Скрипт проверит доступность Ollama, предложит модель и скачает выбранный вариант.

На основном компьютере разработка проверялась с NVIDIA RTX 3060 12 ГБ и 32 ГБ RAM, моделью `qwen3:8b`. Для ноутбука выбирай размер модели по доступным ресурсам — характеристики могут отличаться.

Если Ollama уже установлена, проверить загруженные модели можно командой:

```powershell
ollama list
```

Если команда Ollama не распознаётся в PowerShell, проверь, что Ollama установлена и её каталог добавлен в PATH, либо запусти исполняемый файл по пути установки.

### 5. Запустить Капри

Запусти **run.bat**. Аватар и значок появятся на рабочем столе и в системном трее. Щёлкни правой кнопкой по Капри, чтобы открыть контекстное меню.

## Долговременная память

Локальная память реализована на SQLite и хранится вне Git-репозитория, в пользовательской папке приложения. Она рассчитана на факты, которые пользователь попросил сохранить, а не на автоматическую запись всей переписки.

Капри может использовать сохранённые факты в последующих ответах и удалять их по просьбе пользователя. Для переноса кода на другой компьютер используй Git, а личную базу памяти переносить отдельно — только если это действительно нужно.

## Пользовательский интерфейс

Интерфейс выдержан в стиле Капри:

- почти чёрный фон;
- розовые рамки и основные кнопки;
- бирюзовые и зелёные акценты;
- отдельное многострочное окно ввода команды;
- отдельное окно полного ответа с прокруткой и копированием;
- оформленное окно системного отчёта;
- собственное контекстное меню и возможность закрепить аватар.

Короткие реплики показываются в панели под аватаром, длинные ответы выводятся в отдельном окне.

## Конфигурация

При первом запуске приложение создаёт локальный файл **config.json**. Через меню Капри можно открыть его для настройки.

| Параметр | Назначение |
|---|---|
| `local_ai` | Использовать ли локальную языковую модель |
| `local_model` | Имя модели, установленной в Ollama |
| `use_google_stt` | Дополнительное уточнение распознавания речи через Google |
| `voice` / `tts_engine` | Голос и движок синтеза речи |
| `voice_volume` | Громкость голоса Капри |
| `mic_device` / `mic_gain` / `mic_sensitivity` | Микрофон, усиление и чувствительность |
| `chatter` | Разрешить ли Капри появляться самостоятельно |
| `hide_after_seconds` | Через сколько секунд бездействия аватар автоматически исчезает |
| `sites` / `apps` | Пользовательские сайты и приложения |
| `replies` | Пользовательские ответы на фразы |

После ручного изменения некоторых настроек нужно перезапустить Капри через трей.

## Приватность

- Vosk распознаёт речь локально.
- Если включён параметр `use_google_stt`, распознанная фраза может дополнительно отправляться Google для уточнения.
- Локальные разговоры через Ollama обрабатываются на компьютере и не тарифицируются как облачные API.
- Стандартный Microsoft Edge TTS требует интернета и отправляет текст ответа сервису синтеза речи.
- Журналы, отчёты, настройки и база памяти предназначены для локального использования и должны оставаться вне Git.

Не публикуй личный `config.json`, журналы, базы памяти, секреты API, отчёты диагностики и резервные копии.

## Разработка на нескольких компьютерах

Исходный код хранится в GitHub. После клонирования репозитория на другом компьютере установи зависимости и локальную модель отдельно.

Перед коммитом проверь список изменений:

```powershell
git status --short
git check-ignore -v config.json capri.log memory.sqlite3 models reports backups
```

После проверки изменений:

```powershell
git add .
git commit -m "Describe changes"
git push
```

Перед началом работы на другом компьютере получи последние изменения:

```powershell
git pull
```

Не добавляй в коммиты личные настройки, логи, базы данных, резервные копии и скачанные модели.

## Известные ограничения

- Маршрутизация пока основана на локальных правилах; облачные провайдеры ещё не подключены.
- Qwen3 может ошибаться, отвечать слишком кратко или путать изменяемые сведения. Актуальные данные нужно проверять через поиск.
- Распознавание и синтез речи зависят от настроек Windows, выбранного устройства, наличия сети и конкретного движка.
- После обновления проверяй работу на своём компьютере: окружения Windows и набор установленного ПО различаются.
